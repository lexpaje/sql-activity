# Beginner SQL Exercises

These exercises cover fundamental SQL concepts. Start here if you're new to SQL.

## Topics Covered
- SELECT statements
- WHERE clause
- ORDER BY
- LIMIT
- Basic aggregate functions (COUNT, SUM, AVG)
- DISTINCT keyword

## Exercises

### Exercise 1: Simple SELECT
**Question:** Retrieve all columns from the `employees` table.

### Exercise 2: SELECT Specific Columns
**Question:** Get only the `first_name`, `last_name`, and `email` from the `employees` table.

### Exercise 3: WHERE Clause
**Question:** Find all employees who work in department_id 1.

### Exercise 4: Multiple Conditions
**Question:** Find all employees with a salary greater than 70000 who were hired after '2019-01-01'.

### Exercise 5: ORDER BY
**Question:** List all employees ordered by their salary in descending order.

### Exercise 6: LIMIT
**Question:** Get the top 5 highest-paid employees.

### Exercise 7: COUNT
**Question:** How many employees are there in the company?

### Exercise 8: SUM
**Question:** What is the total salary expense for all employees?

### Exercise 9: AVG
**Question:** What is the average salary across all employees?

### Exercise 10: DISTINCT
**Question:** List all unique job titles in the company.

### Exercise 11: String Matching
**Question:** Find all employees whose last name starts with 'J'.

### Exercise 12: BETWEEN
**Question:** Find all employees with salaries between 60000 and 80000.

### Exercise 13: IN Clause
**Question:** Find all employees in departments 1, 2, or 3.

### Exercise 14: NULL Values
**Question:** Find all employees who don't have a manager (manager_id is NULL).

### Exercise 15: Date Filtering
**Question:** Find all employees hired in the year 2020.

### Exercise 16: COUNT with GROUP BY
**Question:** Count how many employees are in each department.

### Exercise 17: MAX and MIN
**Question:** Find the highest and lowest salary in the company.

### Exercise 18: Products Query
**Question:** List all products with their names and prices, ordered by price ascending.

### Exercise 19: Customers by City
**Question:** List all unique cities where customers are located.

### Exercise 20: Basic Calculation
**Question:** List all products showing product name and price with a 10% discount applied.

## Tips for Success
- Start by understanding the table structure (refer to `setup/schema.sql`)
- Test your queries on small datasets first
- Use LIMIT to preview results before running full queries
- Check the solutions folder only after attempting the exercises yourself
